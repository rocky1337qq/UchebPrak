# AIMCORE — CS2 Aim Training Platform

Веб-ориентированная информационная система тренировочной платформы «AIMCORE» для соревновательной подготовки игроков в CS2.

## История разработки

### День 8-9: Архитектура проекта и HTML-разметка страниц
- Создана структура каталогов проекта в соответствии с требованиями.
- Размещены графические ресурсы в каталоге `images/`.
- Написана семантическая HTML5-разметка для всех 4 страниц проекта (`index.html`, `catalog.html`, `about.html`, `contacts.html`).
- Создана структура для будущей серверной части (`src/`, `src/routes/`, `src/models/`).

### День 10-11: CSS-стилизация
- Разработан файл сброса браузерных стилей `css/reset.css`.
- Создана полноценная стилизация проекта в `css/style.css` в соревновательной киберспортивной стилистике макета Figma:
  - Основные цвета, шрифты и параметры вынесены в CSS-переменные (`:root`).
  - Для построения сеток и адаптивных блоков активно применены **Flexbox** и **CSS Grid**.
  - Добавлены интерактивные `:hover`-эффекты с плавными переходами (`transition`) для всех кнопок, карточек, ссылок и элементов форм.
  - Реализованы анимации бегущей строки киберспортсменов (Marquee), пульсации индикаторов онлайна и эффекты глубины.
  - Настроены медиа-запросы для адаптивности под настольные и мобильные экраны.

### День 12: JavaScript основы и работа с DOM
- Подключены внешние JavaScript-файлы ко всем страницам через тег `<script src>`: `main.js`, `faq.js`, `premium.js`, `servers.js`, `profile.js`.
- Поиск элементов на странице выполняется через `querySelector`, `querySelectorAll` и `getElementById`; состояние хранится в переменных (`let`, `const`), инициализация идёт после `DOMContentLoaded`.
- Изменение содержимого и классов элементов реализовано через `textContent`, `style` и `classList`.
- Добавлены обработчики событий `click`, `submit` и `input`: бургер-меню, аккордеон и живой поиск по базе знаний, фильтрация и сортировка серверов, отправка форм, копирование в буфер обмена.
- Реализованы модальные окна подключения к серверу, списка игроков и оформления подписки; закрытие — по крестику и по клику вне окна. Добавлены всплывающие уведомления и сохранение избранного в `localStorage`.
- Формы обратной связи обрабатываются на клиенте: событие `submit` перехватывается, поля проверяются атрибутами `required`, форма очищается и пользователю показывается сообщение.
- Структура страниц приведена к целевой: `index.html`, `servers.html`, `faq.html`, `premium.html`, `profile.html`; графические и видео-ресурсы перенесены в `assets/images/` и `assets/videos/`.
- Обращения к серверному API (`/api/...`, `/auth/steam`) временно убраны — фронтенд работает автономно, вызовы будут восстановлены на этапе серверной разработки.
- Исходный код очищен от комментариев; в браузере все страницы, стили и скрипты загружаются без ошибок в консоли.

### День 13: Адаптивная верстка с clamp()
- Сайт протестирован и скорректирован для разрешений **425px**, **768px**, **1024px** и **1440px**; горизонтальная прокрутка страницы отсутствует.
- В CSS добавлены/уточнены media queries для основных breakpoints (`1024px`, `900px`, `768px`, `600px`, `425px`) для перестройки сеток, навигации, карточек, фильтров и таблиц.
- Фиксированные размеры шрифтов и отступов заменены на `clamp()` в стилях страниц (`style.css`, `servers.css`, `faq.css`, `premium.css`, `profile.css`) для плавного масштабирования между мобильными и десктопными экранами.
- Меню на мобильных работает как бургер-меню: на узких экранах навигация скрывается и открывается по кнопке-переключателю.
- Для медиа-контента задано ограничение `img, video { max-width: 100%; height: auto; }`, чтобы изображения и видео не выходили за границы контейнеров.
- Контейнеры с широким контентом (ряд режимов серверов, таблица сравнения тарифов) обрабатываются через внутреннюю прокрутку/обрезание без появления горизонтального скролла всей страницы.

│   ├── faq.html            # База знаний, поиск, аккордеон и форма поддержки
│   ├── premium.html        # Тарифы подписки и модальное окно оформления
│   ├── profile.html        # Личный кабинет игрока
│   ├── css/
│   │   ├── style.css       # Базовые стили и CSS-переменные
│   │   ├── servers.css     # Стили каталога серверов
│   │   ├── faq.css         # Стили базы знаний
│   │   ├── premium.css     # Стили страницы подписки
│   │   └── profile.css     # Стили личного кабинета
│   ├── js/
│   │   ├── main.js         # Главная: видео, счётчики, бургер, интерактивные блоки
│   │   ├── servers.js      # Фильтры, поиск, модалки и телеметрия серверов
