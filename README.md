# AIMCORE — CS2 Aim Training Platform

Веб-ориентированная информационная система тренировочной платформы «AIMCORE» для соревновательной подготовки игроков в CS2.

## Текущий этап: День 8-9
**Архитектура проекта и HTML-разметка страниц**

### Выполненные задачи:
1. Создана корневая папка проекта и организована структура каталогов в соответствии с архитектурой приложения.
2. Подготовлены пустые стилевые файлы (`css/reset.css`, `css/style.css`) и скрипт (`js/script.js`).
3. Размещены графические ресурсы (логотипы, аватары игроков, фон) в каталоге `images/`.
4. Написана семантическая HTML5-разметка для всех страниц проекта:
   - `index.html` — Главная страница платформы (Hero, PRO-игроки, преимущества, статистика, этапы подготовки, призыв к действию).
   - `catalog.html` — Каталог игровых серверов (Retake, DM, Prefire, Duels, AWP) и тарифов подписки.
   - `about.html` — О платформе и компании ООО «АИМКОРЕ» (миссия, процессы, архитектура модулей, FAQ).
   - `contacts.html` — Контактная информация, реквизиты, форма обратной связи и схема проезда.
5. Использованы семантические теги HTML5: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
6. Создана структура для будущей серверной части (`src/`, `src/routes/`, `src/models/`).

## Структура проекта
```
YERKINinTHEmiddle/
├── public/
│   ├── index.html          # Главная страница
│   ├── catalog.html        # Каталог серверов и подписок
│   ├── about.html          # О нас и описание системы
│   ├── contacts.html       # Контакты и форма обратной связи
│   ├── css/
│   │   ├── reset.css       # Сброс стилей
│   │   └── style.css       # Основные стили проекта
│   ├── js/
│   │   └── script.js       # Клиентские скрипты
│   └── images/
│       ├── logo.png        # Логотип проекта
│       └── products/       # Карточки и графика
├── src/
│   ├── server.js           # Точка входа Express-сервера
│   ├── routes/
│   │   └── api.js          # API-маршруты
│   └── models/
│       ├── database.js     # Подключение к БД
│       └── initDatabase.js # Инициализация таблиц БД
├── database.db             # База данных SQLite
├── .env                    # Переменные окружения
├── .gitignore              # Исключения для Git
├── package.json            # Манифест проекта
└── README.md               # Документация проекта
```
